# Pinqle MVP

「アイドルが行った場所」を地図で探せる静的サイトの試作です。

## 使い方
1. `index.html` と `data.json` を同じ場所に置く
2. `data.json` のサンプルを実データに差し替える
3. Web上に公開するだけで動作します

## MVPの機能
- 地図表示
- グループ絞り込み
- ジャンル絞り込み
- キーワード検索
- スポット一覧と地図の連動
- 現在地から近い順
- 出典確認済み/要確認の表示
- メンバー絞り込み
- 最大5地点を選択してGoogle Mapsで徒歩ルートを開く

## 0円で公開する

GitHubにこのフォルダを置き、VercelまたはNetlifyへ接続します。独自ドメインを使わなければ公開費用は0円です。

ローカル確認は、このフォルダで `python3 -m http.server 8000` を実行して `http://localhost:8000` を開きます。ファイルを直接開くとブラウザーが `data.json` の取得を拒否する場合があります。

`schema.sql` はSupabase接続用の下地です。接続前にRLSポリシーを適用してください。ブラウザーへ `service_role` キーを入れてはいけません。

## 登録データについて

初期の架空データ3件は削除し、BOYNEXTDOOR公式YouTubeで確認できる6地点へ差し替えました。RIWOOの東京3地点、JAEHYUN・RIWOO・WOONHAKの高円寺2地点、SUNGHO・TAESAN・LEEHANの箱根1地点です。出典URLは各カードから開けます。住所・営業状況は変更される場合があるため、来店前の再確認が必要です。

公式X・Instagram由来の候補3地点（Vaji spice、VERVE COFFEE ROASTERS YOYOGI PARK、ELLA RECORDS）も追加しています。投稿の存在・時期と店舗は複数情報で一致していますが、公式投稿の直接URLを取得できていないため `verified: false` とし、画面では「要確認」と表示します。

JAEHYUNの追加地点として、公式高円寺Vlogで確認できるカプセル楽局 高円寺店とBelphegolを登録しました。SUNGHOについては推測の飲食店を登録せず、全員参加の『AND,』夜行コンセプト撮影地として複数メディアで一致する天空橋駅を要確認で登録しています。
